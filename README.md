# Информатика — Интерактивная система обучения

Интерактивная система поддержки курса **«Информатика»** для студентов 4 курса факультета **прикладной информатики в государственных информационных системах**.

## Возможности

- **6 лекций** по ключевым темам курса с подробным теоретическим материалом
- **6 интерактивных тестов** (48 вопросов) с мгновенной проверкой и пояснениями
- **Отслеживание прогресса** — визуальная статистика изучения материалов
- **Сохранение результатов** — прогресс хранится в браузере (localStorage)

## Темы курса

1. Информационные системы в государственном управлении
2. Базы данных и СУБД в информационных системах
3. Сетевые технологии и протоколы
4. Информационная безопасность
5. Проектирование информационных систем
6. Системы поддержки принятия решений и анализ данных

## Запуск

### Способ 1: Двойной клик
Откройте файл `index.html` в любом браузере.

### Способ 2: Ярлык (скрипт)
- **Windows**: запустите `launch.bat`
- **Linux/macOS**: запустите `./launch.sh`
- **Linux (GNOME)**: скопируйте `Informatika.desktop` на рабочий стол

### Способ 3: Локальный сервер
```bash
# Python
python3 -m http.server 8080

# Node.js
npx serve .
```
