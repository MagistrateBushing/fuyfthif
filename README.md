# Информатика — Интерактивный курс

Интерактивная система для поддержки курса «Информатика».

## Разделы курса

- **Системы счисления** — теория + интерактивный конвертер + практические задания
- **Логические операции** — теория + построитель таблиц истинности + симулятор логических вентилей
- **Алгоритмы** — теория + визуализация сортировок (пузырьковая, выбором, вставками)
- **Кодирование информации** — теория + кодировщик текста + калькулятор объёма
- **Архитектура ЭВМ** — теория + интерактивная схема компьютера
- **Тесты** — по 10 вопросов для каждого раздела с подсчётом результата

## Запуск

### Способ 1: Открыть файл
Откройте `index.html` в любом современном браузере (Chrome, Firefox, Edge).

### Способ 2: Ярлык
- **Windows:** запустите `launch.bat`
- **Linux:** запустите `launch.sh` или используйте `Информатика.desktop`
- **macOS:** запустите `launch.sh`

### Способ 3: Онлайн
Приложение также доступно онлайн — см. ссылку в описании.

## Технологии

- HTML5
- CSS3
- JavaScript (Vanilla)
- Без внешних зависимостей — работает полностью автономно

## Возможности

- Адаптивный дизайн (мобильные устройства и десктоп)
- Отслеживание прогресса (сохранение в localStorage)
- Интерактивные упражнения и конвертеры
- Тесты для самопроверки
- Работает без интернета (после загрузки)
