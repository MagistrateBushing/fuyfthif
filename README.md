# РМ СТО ВЭД — Рабочее место специалиста таможенного оформления

Интерактивная система обучения для **специалиста таможенного оформления внешнеэкономической деятельности (ВЭД)**.

## Возможности

- **6 разделов** по ключевым темам ВЭД с подробным теоретическим материалом
- **6 интерактивных тестов** (48 вопросов) с мгновенной проверкой и пояснениями
- **Отслеживание прогресса** — визуальная статистика изучения материалов
- **Сохранение результатов** — прогресс хранится в браузере (localStorage)

## Темы курса

1. Основы внешнеэкономической деятельности
2. Таможенное оформление и декларирование
3. Товарная номенклатура ВЭД ЕАЭС
4. Таможенные платежи и пошлины
5. Валютный контроль в сфере ВЭД
6. Технологии удалённого доступа и ПО для ВЭД

## Запуск

### Способ 1: Двойной клик
Откройте файл `index.html` в любом браузере.

### Способ 2: Ярлык (скрипт)
- **Windows**: запустите `launch.bat`
- **Linux/macOS**: запустите `./launch.sh`
- **Linux (GNOME)**: скопируйте `RM-STO-VED.desktop` на рабочий стол

### Способ 3: Локальный сервер
```bash
# Python
python3 -m http.server 8080

# Node.js
npx serve .
```
